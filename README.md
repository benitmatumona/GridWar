# GridWar

GridWar is a real-time multiplayer robot battle server built with C# and .NET. It supports concurrent TCP clients using asynchronous I/O and a single-threaded game loop to ensure safe and consistent game-state management.

## Features

- Multiplayer robot battles.
- Player registration and removal.
- Automatic assignment of available player positions.
- Real-time player movement and interactions.
- Match elimination and winner determination.
- Match history and replay functionality.
- Live spectator view.
- Global leaderboard.

## Technology Stack

- **Language:** C#
- **Framework:** .NET / ASP.NET Core
- **Networking:** TCP, SignalR
- **ORM:** Entity Framework Core
- **Database:** PostgreSQL
- **Containerisation:** Docker
- **Orchestration:** Kubernetes
- **Testing:** xUnit, Testcontainers
- **CI/CD:** GitHub Actions
- **Container Registry:** GitHub Container Registry (GHCR)
